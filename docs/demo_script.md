# Demo Script

Last updated: 2026-05-16

1. Open Bubbles and show `MiniMax ready`, voice readiness, and the Tavily connector.
2. Say `Hi Bubbles, do me a research on MiniMax Token Plans`.
3. Confirm Bubbles searches with Tavily, writes the full cited report in chat, and speaks `Please look in the chat panel for the response.`
4. Ask a follow-up such as `What are the tradeoffs?`.
5. Confirm Bubbles answers from the latest report context without starting a new search unless the prompt asks for search/research/latest information.
6. Ask `read the research output` only to confirm the report remains available in chat; long TTS playback should still use the chat-panel prompt.
7. Show MiniMax direct media generation for image or music if needed. CI/demo fixture artifacts remain acceptable for media only.

Do not demo removed Gmail, Calendar, Local Files, Web Search fixture, generic MCP command, or MiniMax CLI flows.
